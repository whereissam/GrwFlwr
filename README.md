# Flower Collaborative Agent Hackathon 2026

The Collaborative Agent Hackathon is a one-day event for building open-source, collaborative AI agents using Flower. 

## Our Idea: GrwFlwr - your agentic watering advisor

![Pitch](assets/pitch.png)

This agentic app helps you, a smallholder farmer, whether to water today,
combining live weather, locally recorded farm data, and a federated-learning
model - reasoned over by **Flower's Endeavor model**.
